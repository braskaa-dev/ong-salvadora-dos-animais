# ONG Salvadora dos Animais

Projeto de website desenvolvido para a ONG Salvadora dos Animais, com o objetivo de apresentar a organização, seus projetos e possibilitar o cadastro de voluntários.

## Funcionalidades

- Navegação entre as páginas da aplicação;
- Apresentação dos projetos da ONG;
- Formulário de cadastro de voluntários;
- Validação dos campos do formulário;
- Persistência dos dados utilizando localStorage;
- Navegação dinâmica utilizando JavaScript;
- Interface responsiva;
- Componentes de feedback para o usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- SweetAlert2
